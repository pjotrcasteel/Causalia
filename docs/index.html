The gap between unit tests and production

The code can be correct.
The ordering can still be wrong.

Normal tests usually exercise one convenient ordering. Distributed systems get all the inconvenient ones too. Causalia lets your test control those orderings deliberately and verify the business guarantee that must survive them.
